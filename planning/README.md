# Planning and architecture roadmap

This directory contains the long-term design and migration proposal for a portable BESHStatNG statistical engine, reusable spreadsheet application layer, preserved Windows Excel-DNA product and future Office.js/WebAssembly product. The main document is [`BESHStatNG_CrossPlatform_MasterPlan.md`](BESHStatNG_CrossPlatform_MasterPlan.md).

The plan is a **development guide**, not a statement of which capabilities have already shipped. For the present implementation, consult the checked-in source, each project's README, owner acceptance records and the relevant engineering reports in [`../docs/architecture/`](../docs/architecture/README.md). The owner-confirmed status as of 7 November 2026 includes the accepted Office host, completed Windows portability inventory and software migrations through comparison/agreement/PSM Love plot preparation. **The next authorized implementation concerns survival and SPC chart payloads**; it has been prepared but not accepted. Accepted software batches are not proof of scientific-golden results, native Excel chart equivalence or Mac/Online release, and the scientific/native Gate C restrictions remain unmet.

The earlier [`Windows portability audit proposal`](BESHStatNG_Phase04A_Windows_Portability_Audit_20261018.md) is historical context; the comprehensive member audit and subsequent extraction evidence now reside in [`../docs/architecture/`](../docs/architecture/README.md) and immutable `evidence/` packets. The audit identifies WinForms, UDF and charting code that should be separated into Core/Common versus host-specific adapters. Work on Windows compatibility and new Windows features should preserve reusable statistical and output contracts for later Office.js adoption. LibreOffice compatibility is an architectural consideration only; no Python/UNO bridge implementation is currently part of the work.

When updating the roadmap, reconcile it with actual project targets, registered analysis handlers, supported Office UI, fixture coverage and the latest owner-reported Excel smoke tests. Keep proposed features visibly distinct from production functionality.
